# Workshop Plan (suggested)

Adjust timing to your class. Each block follows **SENSE → PROCESS → ACT**.

| Block | Time | Topic | Handbook chapter | Hands-on |
|---|---|---|---|---|
| 0 | 15 min | *(Optional)* Tinkercad/Arduino LED blink concept demo | – | Instructor demo only |
| 1 | 45 min | Computer, program, compiler, firmware | 01_Basics ch. 1–2 | Discussion: find embedded systems around you |
| 2 | 30 min | Microcontroller vs microprocessor, memory | ch. 3–4 | EN-button RAM/Flash demo |
| 3 | 40 min | ESP32 intro, GPIO, pins | 02_ESP32 ch. 5–7 | Identify pins on the real board |
| 4 | 45 min | Install IDE, upload, Serial Monitor | ch. 8 | Everyone uploads *Hello ESP32* |
| 5 | 60 min | LED + Button | 03_Basic_Experiments | Blink patterns; button controls LED |
| 6 | 90 min | LDR, HC-SR04 | 04_Sensors | Night lamp; obstacle detector |
| 7 | 90 min | DHT11, MQ-2, Flame, TCS3200 | 04_Sensors | Read raw values, apply threshold |
| 8 | 60 min | Mini project | 05_Mini_Projects | Choose one and build |

## Instructor tips
- Prepare a **pre-workshop checklist** for students: laptop, Arduino IDE installed, driver installed, data cable.
- Keep 2–3 spare boards and cables.
- Teach the order: *understand → check voltage → wire → test program → observe raw values → threshold → output.*
- Stop and verify wiring of every student before power-up when using HC-SR04 ECHO and MQ-2 AO dividers.
