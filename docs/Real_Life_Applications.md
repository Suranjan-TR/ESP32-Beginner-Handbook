## Educational prototype vs certified safety system

| | Educational prototype (this course) | Certified safety system |
|---|---|---|
| Sensor | Low-cost hobby module | Approved, calibrated detector |
| Testing | Classroom testing | Standards testing (e.g. national/international norms) |
| Failure handling | Usually none | Fault monitoring, backup power, redundancy |
| Purpose | Learning SENSE → PROCESS → ACT | Protecting life and property |
