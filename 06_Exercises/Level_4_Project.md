# Level 4 — Mini Project

Choose **one** and complete it. Submit: circuit diagram, code, photos, and a one-page report.

## Option A — Smart Room Monitor
DHT11 + LDR + HC-SR04 + LED/buzzer:
- Show temperature, humidity and light level.
- Warn when the room is too hot.
- Turn on a lamp when dark and someone is close (< 100 cm).

## Option B — Parking Assistant
HC-SR04 + buzzer + 3 LEDs: green far, yellow near, red very near, beeping faster as distance falls.

## Option C — Colour Sorter Demonstrator
TCS3200 + LEDs: light a different LED for each colour and print the bin number.

## Option D — Safety Demonstrator (prototype)
Flame + MQ-2 + LED/buzzer with a reset button and a documented test plan. State clearly that it is **not** a certified safety device.
