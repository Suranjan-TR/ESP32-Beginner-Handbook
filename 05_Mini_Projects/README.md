# Mini Projects

Five beginner projects on the **physical ESP32**. Each one is a complete **SENSE → PROCESS → ACT** system. Do the matching sensor chapter first.

| # | Project | SENSE | ACT | Folder |
|---|---|---|---|---|
| 1 | Automatic Night Lamp | LDR | LED | [Automatic_Night_Lamp](Automatic_Night_Lamp/README.md) |
| 2 | Obstacle Detector | HC-SR04 | Buzzer + LED | [Obstacle_Detector](Obstacle_Detector/README.md) |
| 3 | Temperature Warning | DHT11 | LED + buzzer | [Temperature_Warning](Temperature_Warning/README.md) |
| 4 | Gas Warning Prototype | MQ-2 | Buzzer | [Gas_Warning_Prototype](Gas_Warning_Prototype/README.md) |
| 5 | Smart Safety Demonstrator | Flame + MQ-2 | LED + buzzer | [Smart_Safety_Demonstrator](Smart_Safety_Demonstrator/README.md) |

> Projects 4 and 5 are **educational prototypes, not certified safety devices**.

Open the `.ino` file inside each folder in Arduino IDE (the folder name must equal the file name, which it already does).
Reference diagrams: [LED](../03_Basic_Experiments/LED_Blink/images/led_circuit.svg) · [Buzzer](../images/buzzer_circuit.svg)
